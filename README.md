## Getting Started

### Prerequisites
Make sure you have Python installed along with a Jupyter environment. Common dependencies may include:

- Python 3.x
- Jupyter Notebook / JupyterLab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- PyTorch or TensorFlow (depending on notebook requirements)

### Running the notebooks
Open the notebook files in Jupyter and run the cells in order:

```bash
jupyter notebook
```

Then navigate to the desired assignment or project notebook.
